
# API de Artículos: articulo_api_mysql_final

## Descripción
Proyecto de API REST desarrollado con Java y Spring Boot, conectado a una base de datos MySQL.

## Tecnologías utilizadas
- Java
- Spring Boot
- MySQL
- XAMPP
- Postman

## Funcionalidades
- Consultar artículos.
- Buscar artículos por ID.
- Registrar artículos.
- Modificar artículos.
- Eliminar artículos.

## Cómo ejecutar el proyecto
1. Clonar el repositorio.
2. Configurar la conexión a MySQL.
3. Ejecutar la aplicación Spring Boot.
4. Probar los endpoints utilizando Postman.
